# Phase 11.7 — Maintainer notes

Open the User Manual and focus it by clicking its header or a tab. Ctrl+0 opens the access dialog when the default view is active; enter the configured PIN. Ctrl+0 again while the manual is focused restores the default view without a PIN. Outside the focused manual the browser shortcut is unaffected where supported. Some browsers reserve Ctrl+0 for zoom reset. The PIN is client-side presentation control only, not authentication. Session persistence and administrator authorization are unchanged. The public interface has no mode labels or switch buttons.
