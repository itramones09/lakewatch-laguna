# Phase 11.10 — Station summary reports

Adds a six-parameter matrix above the existing detailed report builder. Uses the shared merged dataset, derives periods dynamically, supports monthly, quarterly and annual filters, exact-value means with explicit counts, original monthly readings, CSV and landscape browser PDF. Missing and qualified values are not imputed. The separate annual archive is not merged into monthly means. No database or backend changes. Phase 11.9 partial dataset coverage remains unchanged.
