# Phase 10 — New Module Guide

**Monitoring Stations:** Choose a station and date. Select a parameter inside *Parameter Interpretation*. A reading such as `<0.1` is reported as below the measurement reporting limit, not exactly zero.

**Analytics / Multi-station comparison:** Select a parameter, one reporting month and several stations. Numeric bars use only exact comparable values; missing and qualified values remain explicitly listed.

**Analytics / Predictive modeling:** Choose monthly series for an available station or lake-wide annual historical data. The current monthly archive cannot support a current station forecast. Historical 1990–2000 modelling is labeled retrospective, with held-out mean absolute error (MAE) and fit R².

**Reports:** Choose selected/all stations, month and parameter; preview and download PDF. Includes appropriate source notes and limitations. Download is generated by Render when connected.

**Lake Map / Incidents:** View dated administrator-documented reports. If signed in, submit only reports supported by evidence; the location marker is aligned to a known station area, not a proven incident GPS point.

**Lake Context:** View Open-Meteo daily rainfall and *air* temperature (not lake sampling measurements), then consult or add separately sourced context records for lake level, tributary flow, rainfall and water temperature.

**Administration:** Sign in through Manage Data. Existing administrator credentials are valid for incident and context submissions in the same browser session.
